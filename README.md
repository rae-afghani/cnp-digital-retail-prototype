# CNP Digital Retail Prototype

Presentation prototype for a refreshed Cars & Pickups digital retail experience.

## Pages
- `index.html` — fully fleshed homepage based on the homepage refresh strategy
- `inventory.html` — interactive inventory sample using six vehicles captured from CNP inventory during the Sept. 23, 2026 review
- `vdp.html` — prototype vehicle detail page

## Deployment
This is a static site and can be imported directly into Vercel. No build command is required.

## Notes
- Vehicle titles, stock numbers, mileage, locations and featured prices were captured from carsandpickups.com on Sept. 23, 2026. Inventory changes frequently.
- Some prototype imagery is representative photography rather than CNP listing photography.
- Monthly payments are labeled example estimates and are not financing offers.
- CNP custom build pricing in the concept follows the provided structure: standard builds +$4K or +$5K; dually builds +$5K.
- This is presentation prototype code, not production code.
